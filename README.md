# Finder

fake dating app for 9/1/2026

Swipe through the profiles in a continuous loop.

Edit your own or other profiles. Add new ones too

## Tech Stack

- React Native
- Expo
- TypeScript
- JavaScript/TypeScript state management
- Expo Image Picker
- Expo Camera

## Getting Started

### Requirements

- Node.js
- npm
- Expo
- Xcode (for iOS development)
- iOS Simulator or an iPhone

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/finder-app.git
cd finder-app
```
Install dependencies:
```bash
npm install
```

Start the Expo development server:
```bash
npx expo start
```


To run on the iOS Simulator:
```bash
npm run ios
```
